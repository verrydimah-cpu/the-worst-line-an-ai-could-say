A tiny Node program that writes the worst pickup line an AI could say — a machine that has analysed your heart rate, search history and location, concluded you are soulmates, and helpfully offered to notify your exes — to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`). One line, 140 characters or fewer, flat, over-helpful and faintly ominous, exactly as a machine trying to charm a person would deliver it.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
